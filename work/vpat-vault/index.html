VPAT Vault

A free-beta accessibility toolkit: a terminal scanner, a Chrome extension and nine Claude prompts that turn real evidence into a VPAT 2.5 draft without inventing a single rating.

VPAT Vault is in free beta and changing week to week, so this page is a snapshot from November 2026.

Take · T-04
An accessibility report nobody can find is a liability with a cover page.

A VPAT is a promise someone else relies on. A buyer reads "Supports" and assumes a person checked. Most teams either pay for an audit they can't repeat, or paste scan results into a template and hope. I built VPAT Vault so the evidence and the claim never come apart.

A clean scan is not a clean bill of health

Automated checks find some accessibility problems, not all of them. So the rule the whole toolkit is built on is simple: a scan can draft "Partially Supports" at most. It never writes "Supports". On the demo store, one crawl found 30 problems on 5 pages and drafted 5 criteria. The other 50 were left out, not rated, because no tool can see them. A reviewer still owns every row.

Three tools, one pipeline

The WCAG CLI crawls a site, a signed-in app or a codebase on your own machine and writes a bug sheet, a whole-site summary, reviewer files and a VPAT draft, with PDF, Excel and Word exports.

The Chrome extension scans the page you're on with axe-core, keeps everything local, and exports JSON. wcag-scan --from-evidence turns those exports into the same bug sheet and draft.

Nine prompts run inside Claude Code or Codex. They turn reviewed evidence into ITI-labelled rows, and a small renderer escapes them into fixed HTML. Every tool is free while it's in beta.

Roadmap

From working tools to a VPAT a team can publish with confidence.

  1. Shipped

    Prompt workflow

    Nine prompts, a validator, a report schema and a renderer that escapes everything.

  2. Shipped

    Pages, whole sites, signed-in apps and codebases. Bug sheet, site summary, VPAT draft, PDF, Excel and Word.

  3. In progress

    Chrome scanner

    Works today as an unpacked extension. Chrome Web Store listing is next.

  4. Planned

    Attach context

    Bring manual test notes, screen reader results and screenshots in beside the scan.
