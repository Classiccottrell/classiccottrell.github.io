Work / VPAT Vault / Design system

A design system an agent can follow. And prove it did.

Most design systems are written for designers. They assume a reader who can look at a page and feel that something is off. Agents can't feel it. They can read a rule and run a check. This is what a design system looks like when it is built for that reader too.

Every example is real, from the VPAT Vault build, November 2026.

The moment

The moment

I asked an agent to remove every line on the VPAT Vault site that talked about buying it. It did. Then a test failed.

The test bans commerce words on every page, and it had found "price" inside a CSS class called .price. The rule was right, it was just too blunt. We narrowed it to how the word shows up in copy, and now "no commerce language while it's a free beta" isn't a line in a style guide hoping to be read. It runs on every change.

That's the whole idea. Right now we hand agents the same brand book we hand people, then review their output by eye. Review is the slow part. An agentic design system moves the review into the system.

Layer 1 · Tokens

The look, as values.

Tokens live in the stylesheet that ships, not in a separate library that can drift. A test fails if any page adds inline styles or a second stylesheet.

  • --bg #EFEBE4 paper
  • --surface #F8F5EF sheet
  • --ink #0E0E0C type
  • --muted #55514A captions
  • --signal #A3402B one accent
  • --field-2 #CCD8CA quiet field

"Calm type" is a number, not an adjective. VPAT Vault's display face tops out at 4.75rem, so an agent making a social card knows the headline is about 64px on 1200 × 630 and nothing is bigger.

Layer 2 · Rules

Rules that carry their reason.

  • Real before drawn. The hero, the share card and product shots are captures of real tool output. Illustration supports, it never proves.
  • Calm type. Headlines lead, they don't shout. No poster-scale display type, no giant numbers.
  • Honest claims. Every image and line must survive a reviewer asking "is that true?"

The reason is the part agents need most. A rule covers the cases you thought of. Its reason covers the one you didn't, like whether an AI-generated illustration can sit in the hero. (It can't. Rule one says why.)

Layer 3 · Voice

Voice as data, not adjectives.

"Friendly but professional" gives an agent nothing to act on. A names table, two lists and fixed-length boilerplate do.

Must say

  • Pair every scan claim with its limit
  • A person signs off every row
  • It runs on your computer
  • It is not an audit, certification or legal advice

Never say

  • compliant, certified, guaranteed, audit-ready
  • AI-powered, AI drafts
  • buy, price, checkout, shop links
  • seamless, robust, journey, unlock

Boilerplate comes at one line, 50 words and 100 words. An agent trims an approved sentence instead of writing a new one, and new sentences are where claims creep in.

Layer 4 · Recipes

Recipes, not mockups.

A mockup shows what an image should look like. A recipe makes it. The VPAT Vault hero is real scanner output, rendered to HTML and screenshotted, so an agent can remake it after every release and it can't drift from the truth.

# 1. Run a real scan of the demo store
$ script -q tty.log wcag-scan --crawl http://127.0.0.1:8799/ --yes \
    --report-dir ~/wcag-runs/brightside-goods
# 2. Turn the terminal's colour codes into styled HTML
$ python3 render_terminal.py tty.log term.html
# 3. Shoot it at the asset size
$ node shoot.js term.html term.png 1400 788

Layer 5 · Gates

If a rule matters, it's a test.

The VPAT Vault site runs 33 checks on every change. These are the ones that guard the design system, by their real names:

  • stylesheet_defines_token_set
  • all_pages_share_one_stylesheet
  • motion_only_inside_no_preference
  • no_flashing_or_webgl
  • banned_copy
  • no_purchasing_language_or_shop_links
  • no_external_font_or_script_urls
  • h1_skip_link_landmarks_and_alt
  • nav_identical_on_every_page
  • pipeline_has_human_signoff_gate
  • extension_copy_matches_manifest
  • states_nothing_uploaded

The box runs a small version of the real check in your browser. The real one also scans the CSS, catches "certif" outside a disclaimer, and blocks install commands that don't exist.

Layer 6 · Package

One folder, one command.

The art direction, the writing guide, the product facts, the real assets, the fonts with their licences and the capture scripts ship together. The build fails if a guide or a font licence is missing.

$ bash vpat-optimizer/scripts/build_brand_kit.sh
vpat-vault-brand-kit/
  design.md            # art direction
  writing-guide.md     # names, must say, never say, boilerplate
  product.md           # facts and the required disclaimer
  assets/              # share card, hero capture, icon
  fonts/               # three OFL faces + LICENSES.txt
  launch-assets/       # the recipes

The move

Write the rule, then write the check. A rule an agent can't verify is still a wish.

Start with the rule that hurts most when it breaks. For VPAT Vault it was honest claims. Give it a reason, a list and a test, then the next one.
